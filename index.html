SquadTurf

A sports match hosting platform where players post “players needed” requests and others join.

  • User login and profile pages, with hosting and joining of matches.
  • Two-part player rating system (attendance and play quality) stored in the database, with validation for no-show players.
  • Web push notifications and live updates without a page refresh.
  • Installable on phones as a Progressive Web App, with a responsive Tailwind CSS interface, deployed on Render.
