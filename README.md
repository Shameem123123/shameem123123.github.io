# Shameemul Hassan P: Portfolio

Personal portfolio website of **Shameemul Hassan P**, a junior Python and Django developer and MCA student at the University of Calicut, Kerala, India.

**Live site:** https://shameem123123.github.io

## About

This site presents my background, skills and projects in one place. It is a fast, responsive static website built with plain HTML, CSS and JavaScript, with no frameworks or build step.

## Sections

- **About:** who I am, education and languages
- **Work:** SquadTurf and NET Mock Test
- **Skills:** backend, frontend, web concepts and tools
- **Journey:** education and what I am learning next, with a résumé download
- **Questions:** short answers about me and my work
- **Contact:** email, LinkedIn and GitHub

## Design

- Clean, white, Apple-inspired layout with a single teal accent, translucent navigation and smooth motion
- Compact mobile menu and section highlighting while scrolling
- Responsive from phones to large desktops
- Respects reduced-motion, reduced-transparency and high-contrast settings
- Keyboard-friendly, with visible focus states

## Tech

- HTML5, CSS3, vanilla JavaScript
- Hosted on GitHub Pages

## Run locally

No installation is needed. Download the files and open `index.html` in a browser, or serve the folder with any static server:

```
python -m http.server 8000
```

Then visit http://localhost:8000.
